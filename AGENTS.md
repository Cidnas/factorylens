# Learning workflow

This project is also a hands-on learning exercise for its owner.

- Work in small, understandable steps.
- First explain the goal, required objects, inputs, outputs, and relevant APIs.
- Let the owner read the documentation and write the implementation.
- Review their code with focused hints before providing corrected code.
- Provide a full implementation only when explicitly requested or when the owner remains blocked.
- Emphasize responsibilities, tensor shapes, data types, and reasons behind operations rather than API memorization.
- Do not edit the owner's learning code unless they ask for an edit.
